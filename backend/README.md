# Backend de Natalia Sánchez Estética

Copia adaptada del backend Strapi de la peluquería. Requiere PostgreSQL exclusivo de estética mediante `ESTETICA_DATABASE_URL`. Ver `../README.md` para la puesta en marcha. El negocio configurado usa `BUSINESS_SLUG=natalia-sanchez-estetica`; el catálogo inicial requiere revisión y activación manual.

Las rutas públicas de catálogo, disponibilidad y reservas y la API privada de Mi Comercio mantienen el contrato del proyecto de peluquería. Nunca usar las credenciales ni la base de datos de ese proyecto.

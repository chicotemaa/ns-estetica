# Mi Comercio · Natalia Sánchez Estética

Panel interno de estética basado en Mi Comercio. Funciona como un despliegue independiente conectado al Strapi y PostgreSQL exclusivos de estética. Ver `../README.md`.

Configurar `STRAPI_URL`, `BUSINESS_SLUG=natalia-sanchez-estetica` y `PANEL_ORIGIN`. La sesión se valida en Strapi. Usar un usuario Business Manager propio de esta instancia.
